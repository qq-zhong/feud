# Family Feud

try the game here (please ignore the blandness of game selection screen i swear the game looks great!):
https://qq-zhong.github.io/feud/

select one of the 8 games to play the game
in order for the keyboard to serve as the 'buttons' in a game of family feud, click the 'register player X keys' in the bottom right of screen, which will then allow player to select the keys they wish to use as their button

use number keys 1 - 8 to reveal answers after the button is clicked, or use but button 'X' to signal wrong answers

happy feuding!

to test locally:
ng serve -o

to build to /docs and get ready to publish to github io
ng build --output-path docs --base-href /feud/
